# NoteHub — React Notes App

Single-page application for managing personal notes, working with a REST API through TanStack Query.

## 🔗 Links

- **Live Demo:** [https://05-notehub-11-644c.vercel.app](https://05-notehub-11-644c.vercel.app)
- **Source code:** [github.com/vitalii1408/05-notehub](https://github.com/vitalii1408/05-notehub)

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- TanStack Query
- Axios
- Formik
- Yup
- React Paginate
- CSS Modules

## ✨ Features

- Create notes in a modal form with Formik + Yup validation
- Delete notes
- Search notes with debounce
- Pagination
- Loading and error states

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/05-notehub.git
cd 05-notehub
npm install
npm run dev
```

Open the local address shown in the terminal (usually [http://localhost:5173](http://localhost:5173)).
